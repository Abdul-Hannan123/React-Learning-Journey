# ⚛️ Day 02 — React Components

Today I learned about **React Components** and how they work in React.

I learned how to create components, reuse them, export them, and combine multiple components to build a complete UI.

As a small practice project, I created a **Student Card** using three separate React components.

---

## 📚 What I Learned

### 1. React Components

I learned that React applications are built using **components**.

A component is a reusable piece of UI that can contain its own structure and logic.

For example:

- Student Card
- Navbar
- Button
- Image
- User Information

Each part can be created as a separate component and reused whenever needed.

---

### 2. Component Reusability

I learned how components can be **reused** multiple times instead of writing the same code again and again.

This makes React applications:

- ✅ Easier to manage
- ✅ More organized
- ✅ Reusable
- ✅ Easier to maintain
