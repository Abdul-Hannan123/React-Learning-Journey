## Day-11 React API, Storage & Image Gallery

This project is a basic React practice project created to understand **browser storage, API calling, and displaying API data** in a user-friendly layout.

### What I Practiced

* **Local Storage** – storing and retrieving data in the browser.
* **Session Storage** – managing data for the current browser session.
* **API Calling** – fetching data from an external API.
* **Fetch Method** – making API requests using JavaScript's built-in Fetch API.
* **Axios** – making API requests using the Axios library.
* **Image API** – fetching and displaying 30 images from an API.
* **CSS Grid** – arranging the images in a responsive grid layout.
* **Sticky Button** – creating a sticky button that remains visible while scrolling.

### Technologies Used

* React.js
* JavaScript
* Tailwind CSS
* Fetch API
* Axios
* Local Storage
* Session Storage

### Project Overview

The project fetches 30 images from an external API and displays them using a responsive grid. It also includes a sticky button to trigger the API request and provides practical experience with browser storage and different API-calling methods.

This project was built as part of my **React learning journey** to strengthen my understanding of API integration, browser storage, and responsive UI development.
